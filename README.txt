جدول حصصي - تطبيق ويب
=====================
1) ارفع كل ملفات هذا المجلد كما هي إلى أي استضافة تدعم HTTPS
   (مثل Cloudflare Pages أو GitHub Pages أو Netlify).
2) افتح الرابط من متصفح الجوال.
3) افتح قائمة المتصفح واختر "إضافة إلى الشاشة الرئيسية" (Add to Home Screen).
4) بعد أول فتح يعمل التطبيق بدون إنترنت.

ملاحظات:
- التعديلات تُحفظ داخل الجوال نفسه (لا تُزامَن بين جهازين).
- الإشعارات: الإعدادات > التنبيه قبل الحصة. تصل والتطبيق مفتوح أو في الخلفية.
- للتنبيه المضمون: الإعدادات > تصدير الجدول إلى تقويم الجوال (ICS).
- لتحديث التطبيق لاحقاً استبدل index.html في الاستضافة، وغيّر رقم الإصدار في sw.js (schedule-v1).
